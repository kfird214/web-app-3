# משחק REST

משחק שהמצאתי כדי למלא את מטלה 3
המשחק בעל שלבים ואינטרפייס שמזכיר אפליקציות כמו פוסטמאן וכו
אבל בכל שלב המשחק שואל אותך שאלה שמנסה בעצם לוודא שבאמת הבנת את השלב ושהצלחת להתמצא בשלב כדי לענות על השאלה

נעזרתי ב claude כדי
- להמציא data לAPI
- לכתוב קוד שמתאים ל API שהמצאנו ולשים אותו ב structure שיהיה קל לשליפה באופן פרוסידורלי
- עזרה בכתיבת ה-CSS לעיצוב (CSS רגיל בקובץ חיצוני, בלי פריימוורק)

## Install and run

```bash
npm install
npm start
```

`npm run dev` לפתיחת השרת
ניתן לשים env var PORT=XXX
הדיפולט הוא 3000

פתח **http://localhost:3000** בשרת

## אנד פוינטס

| Path       | What it is |
|------------|------------|
| `/`        | המשחק עצמו  מרונדר על ejs כל שלב היא קריאת AJAX חדשה כדי להימנע מריפרש |
| `/schemas` | הסכמה של ה API שנעזרתי ב claude להמציא |
| `/api/...` | ה API שהמצאתי שהמשחק משתמש בו |

## שלבים

כל שלב הוא דזיין שחשבנו עליו ככה שיהיה קל אל קשה פחות או יותר  
השתדלנו להשתמש במידע משלבים קודים כדי שנוכל לוודא הבנה ואינטגרציה בין אנדפוינטס שונים
